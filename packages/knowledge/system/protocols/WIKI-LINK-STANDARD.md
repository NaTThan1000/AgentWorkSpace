# WIKI-LINK-STANDARD · 链接规则

## 一、是否值得链

Wiki 之间只保留“不可替代”的关系。必须同时回答：

1. 目标页能补全当前页哪个具体命题？
2. 删除此链接后，读者会缺少哪块关键证据或方法？

任一问题答不上来，就用纯文本提及或不提。`## 相关页面` 建议不超过 5 条。

## 二、格式

| 场景 | 格式 |
|---|---|
| Wiki 章节引用 raw | `> 📍 来源：[[raw-sources/文件名]]` |
| Wiki 底部来源 | `- [[raw-sources/文件名]]` |
| Wiki → Wiki | `[页面名](./页面名.md#标题锚点)` |
| domain → Wiki | `[页面名](../wiki/页面名.md)` |
| 规则 / README / 外部页面 | 标准 Markdown 链接 |

Wiki 之间不使用双链；raw 的证词关系保留双链。锚点中的 ASCII 空格改为 `-`，`+` 编码为 `%2B`。

## 三、内联与底部镜像

关联到单个段落时，可在段末加入：

```markdown
> 📎 参见：[目标页](./目标页.md#锚点) —— 从某个角度补全本节的具体命题。
```

底部 `## 相关页面` 同时保留一条精简镜像并指向插入段。关联整页或会打断连续论证时只放底部；关联多个段落时只在最关键处内联。

## 四、健康检查

- Wiki 间链接全部带有效锚点。
- 每条相关页面说明关联方式，不只列名称。
- 内联条目存在底部镜像，镜像指针可定位。
- raw 引用使用统一双链格式。
- domain、协议、状态和参考文档不产生双链图谱噪音。
- 新建或拆分 Wiki 后重新判断链接，不照搬旧页链接。
