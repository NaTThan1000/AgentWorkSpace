# CHANGELOG

本文件记录发布包自身的变更。完整的私有仓库历史保留在来源仓库，不随空白搭建包分发。

## [0.11.0] - 2026-08-29

### Changed

- 发布包收敛为独立的知识查询与消化框架：保留 Query、Ingest、检索、证据融合、评分、维护与初始化。
- 初始化向导、范围登记、领域模板和健康检查不再暴露本地专家配置。
- 发布合同改为 64 个业务文件、13 个正式目录，并新增纯 Query 合同。

### Removed

- 移除本地 Agent、专家提示词、Team、Procedure、Method、评测和记忆产品层。
- 移除旧 Agent 健康检查与 Query/Agent 联合合同。
