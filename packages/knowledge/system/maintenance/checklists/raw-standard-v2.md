# RAW_STANDARD_V2 · 核心知识完整的消化稿

> 唯一写作与质量尺度。规则修订：`core-semantic-20260910`。消化、独立复核、历史回测共用；旧规则只解释旧证据。

## 定义与取舍

Raw 保留原文的核心知识观点及理解、判断这些观点不可缺少的支撑，不是逐段复刻，也不是提纲。核心语义不变的前提下精简和重组表达：必要推理链、具体例子、相关数据、反例、限制不能被总结口号替代；铺场、闲谈、情绪渲染、重复说明以及无助于论证的故事枝节可以省略。

逐项做删除测试：删掉它，读者是否会误解观点、失去“为何成立”的解释、无法理解例子的作用，或改变结论的强度与适用范围？会则保留；不会则说明其与核心论证的关系后合理省略。不能用“非核心”三个字豁免困难或不喜欢的内容。完整阅读与完整判断不等于完整照录。

## 内容规则

- R01 原意：保留核心定义、区别、主张、限定、反例、推测语气及适用范围，不改变因果方向或证据强度。
- R02 推理：保留支撑核心结论所需的前提、中间解释、转折和结论之间的联系；可合并重复步骤，不能只剩结论。
- R03 案例：保留必要背景、关键过程、结果及其论证作用；作品名不等于案例。叙事可收为“原因—结果—知识/设计对应”，不必复述无关支线。
- R04 数据：保留影响理解和判断的数值、单位、范围、分母、时间条件、比较对象。不改变证据类型；无关年份、人名、数值不因可机械检出就强制保留。
- R05 背景与枚举：保留概念来源、分类差异和必要形成机制；历史故事只保留解释这些知识所需的因果与对应。删去旁支不得损坏完整分类或论证。
- R06 来源边界：不新增作者没说过的事实、因果、建议或评价。作者本身的存疑与限制仍是正文；AI 的补充另入 Wiki 并标明身份。
- R07 省略：全文 manifest 不漏项；独立审核列出核心观点并定位，逐项检查必要支撑。元数据、广告导航、非语义媒体、严格重复及不影响核心语义的上下文可省略；上下文省略须指向相关核心观点、说明删除为何不损害其理解/论证。混合段落逐要素判断，不能整段豁免。禁止无说明的 optional_supporting。
- R08 媒体：Raw 不嵌图（Markdown、Obsidian、HTML 均禁止）。需要的图像知识可靠读图后写成文字/表格；与已保留正文同义的图可登记重复。无法可靠读出的内容在对应位置标记“未转录”。必要图像知识缺失为 media_limited；已保留核心知识、仅未转录非必要视觉细节的，经独立审核给出具体理由可通过，但回执必须披露，不得宣称已全部转录。图片文件无需为此删除。

## 文风与格式

- R09 自然段承担解释与推理，按完整意思和转折分段。删赘语、合并重复表达，既不一句一行，也不堆大段复述。
- R10 真并列用列表，真步骤用编号，同维度比较用表格；信息结构决定载体。列表不是默认模板，表格不能丢掉理解所需的解释。
- R11 可以重排、合并、改写以改善理解；不设置篇幅、列表比例、压缩率配额，不强制每节“核心洞察”。
- R12 保留 YAML 来源/日期/领域/评分等既有元数据、标题层级和每个 H2 的准确原文定位。来源只在元数据标记。
- R13 正文结束即结束。不在 Raw 底部放来源、AI 批注/存疑、审计矩阵或未消费清单；AI 意见进入阶段包并按需消费进 Wiki，Raw→Wiki 未消费知识只按 raw-list 协议登记。合理省略的原文枝节不是 Raw 未消费知识。

## 参考与执行

主要结构参考为 `raw-sources/从0到1创造开放世界设计流程-天美江岸栖-20260705.md`；2026-09-10 用户认可的本批六篇精简稿（Knowledge commit `01dc49cc615aee9b611cb21bacacea796b7aa567`）进一步校准内容取舍和简洁度。样本是文风参考，不是全库语义金标。通用实例无私人样本时使用 `raw-writing-v2.md` 的合成示例，不依赖不存在的路径。

写作顺序：冻结来源 → 全文 manifest 与阅读 → 识别核心观点和必要支撑 → 精简、重组为连贯消化稿 → 独立全文双向审核 → 定点修复。返修后的 targeted recheck 只复验变更范围、相邻上下文和关联来源，未变裁决由控制器按不可变收据与内容指纹复用，最终仍编译成全文双向收据。不能先写摘要再按字数扩写。

使用 `raw-quality.mjs` 的 prepare / validate / verify。机器检查格式、范围、全集、哈希及证据合同；核心性、必要性、语义与文风由真实独立审核判断。数字缺词扫描只是候选，不自动等于遗漏；结构 PASS 不证明语义正确。

passed：核心知识与必要支撑完整，双向审核无确认缺口；允许带明确披露的非必要视觉未转录。failed：必要信息遗漏、失真、无来源新增或格式/文风违规。needs_review：独立证据不足或未裁决。media_limited：必要媒体信息未可靠读取，不自动推进。重要缺口不能用总分抵消。

消化、复核和回测使用同一规则修订与裁决器；新规则使旧请求/回执失效，不能换标签沿用。历史回测只报告，不隐式修稿；原批准事实保留。新稿最多连续两轮定点返修，仍失败就报告阻断。
