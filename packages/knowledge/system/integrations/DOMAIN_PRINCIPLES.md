# 共享领域原则的查用与维护

领域原则是Knowledge的跨任务知识；由query-principles.mjs按域或DPR稳定ID读取，继续沿真正影响结论的Wiki/raw/公开一手资料追溯。ID或hash只定位版本，不证明正确。遵守 Query 问题路由、证据预算和 Group 规则，普通查阅不写回内容。

原则可来自现有Wiki或已实际阅读的外部证据；保留命题、适用条件、反例、来源独立性和复核触发。约8条是阅读负担信号，不自动删原则，也不为凑数增补。新增实质不同命题用新ID，解释取代关系。

维护必须有明确owner和写范围。没有维护授权时只读；正文、共享原则、Group及历史审批有不同身份，不能因宿主请求分析就反写来源材料。重要价值取舍、结构调整和权限扩大由用户决定。

复核可由本次真实任务的反例、来源改变或已授权维护触发；本包不附带定时任务或预先授权。每次说明维持/修订/存疑、证据、条件和恢复依据；未覆盖的域不称已复核。专业分析工作流由外部宿主拥有，共享原则仍留Knowledge。
