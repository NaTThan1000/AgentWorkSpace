# 游戏示范：从没有感觉到可继续的具体问题

性质：合成行为示例，未发生真人共创。使用下方U/I标记追踪，不创建实际RAW/IDEA/DEC。

## 输入与首次刺激

U1：“想做小队游戏，让我的安排显得聪明。别让我一直盯倒计时。”当前目标是假设中的安排成就感；不推断永远厌恶时间策略。

Agent初稿I1“元素连击”、I2“阵营配合”。这两项太抽象，无法看到玩家安排改变什么。U2：“都没感觉，能不能让我看见一轮在做什么？”这是没看懂/没对上，不是正式拒绝。

## 改表达并扩大机制差异

依据U1/U2，Agent停止追加标签，给三个具体刺激：

- I3 改通路：盾手推箱挡住正门，敌人改走侧廊，弓手从空出的射线击中背后目标。若箱子推晚，射线仍被挡。聪明感假设来自预先改变空间。
- I4 配情报：两名侦察只能各看一门，先找到诱饵声音再决定全队绕另一门拦截；代价是放弃本轮宝箱。差异在信息分配与承诺。
- I5 传状态：重甲接住晶球，法师冻结倒计时，轻装越缝隙送球开门；也可原地爆破清障。差异在物品状态和能力接力，但倒计时可能触碰U1意图。

三项均保留来源为Agent变形，I5只是条件性探索，不把用户“不盯倒计时”删除。

## 用户反馈驱动变形

U3：“第一种有点接近，但推箱像唯一解。我希望怪物也会把局面搅乱。”这表示对改通路片段有兴趣，未接受整包。

使用SCAMPER的R/适配操作：I6继承I3，箱子不由玩家直接推完，先由盾手摆方向、敌人冲撞带走箱子。局面中玩家面对两只敌人：挡住一条路线会让另一只进入射线，但可能打开逃路。新增关系是借敌行动改变空间；不是推箱改名。

I7作为边界探索：不移动箱子，玩家轮换站位交换射线；差异是可预测布置与利用敌行为。两者都保留，因为当前没有正式淘汰授权。

## 按需材料与比较

现在缺口是“敌动作可预测到什么程度才公平”。若工具可用，可从Knowledge找信息公平/可读性的材料，并以Web反例补充；若未执行，仅记查询目的，不能写已被研究证明。多源不会替用户选择体验。

当前比较：I6可能有借力惊喜，也可能难读；I7更清楚，但可能趋于唯一解。建议先向用户展示同一小局面在两方案下的一轮差异，而不自动实现原型。
