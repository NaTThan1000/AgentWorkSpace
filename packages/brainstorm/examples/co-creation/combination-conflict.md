# 收敛反例：构件有价值，合起来却抵消

性质：合成案例，所有偏好均为题设，不是真实用户反馈。

输入U1：“想要探索时敢于试新路，又希望撤退有取舍。”Agent得到：
I1 每步随时重来；I2 未带回线索会丢；I3 带回线索永久解锁捷径；I4 撤退不耗任何东西；I5 远路能绕开敌人。

错误拼包P0把I1～I5全装入，理由是每项都有价值。但若I1允许撤退后立即重来所有结果，I2的丢失不构成承诺；I4与I5也可能让撤出没有代价。这是具体规则关系冲突，不能靠平均分修复。

Agent展开一轮：玩家拿到线索后见到岔路，试远路失败，按I1重来回到拿线索前，I2损失被消解。于是形成两个完整方向：
- P1 安心试路：可撤回局部动作、保留发现，挑战来自解读路线；不声称有押注损失。
- P2 信息押注：进岔路前可回营保住信息，进入后才失去该次未带回线索；不能无限回到承诺前。

用户若说“P1更像我想要的”，这仍需区分倾向与采用。若本轮只愿继续P1，不制造另外两包；保留P2及冲突说明即可。没有选择可保持开放。

交接应说明当前的回退边界、被排除规则、关键未知和决定状态。若后续GAD分析损失是否必要，使用其实际报告；分析建议不能改写用户已选P1。
