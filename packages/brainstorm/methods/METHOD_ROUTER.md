# 方法路由

先识别当前卡点，只加载会改变下一步的正文。类别用于查找，不形成固定阶段或确认门。用户需要对具体内容碰撞，Agent自主选择认知操作；已有锁定方向不因换方法重开。

## 路由表

| 当前阻塞 | 方法 | 实际变换与退出信号 |
|---|---|---|
| 原话很多且易丢 | `brain-dump` | 保留原话/歧义，能接续则继续，不先长问卷 |
| 问题太宽、太窄、理解错 | `how-might-we` | 用具体解法试工作框架的宽窄 |
| 前提未经确认却锁住答案 | `assumption-reversal` | 撤去/反转关键假设，保留事实与用户约束 |
| 惯例被当作必要条件 | `first-principles` | 依据分类，重建必要关系，缺事实先查 |
| 有未来体验但当前动作脱节 | `future-backcasting` | 从可观察未来回推条件，再向前检查动作 |
| 已有片段想变局部 | `scamper` | 选择有用变换，说明保留/改变关系，不必七类全跑 |
| 惯性明显，缺新刺激 | `forced-connections` | 预先选刺激，属性→桥接→场景，不事后编随机 |
| 有跨域材料可借关系 | `analogy` | 来源→映射/失配→目标片段，非题材相似 |
| 多维关系构成不同配置 | `morphological-matrix` | 定义维度、有限抽取、一致性与完整片段 |
| 正向思路重复，遗漏失败原因 | `reverse-brainstorming` | 失败因果链→可改变的正向机制 |
| 太保守，极端可能藏有效成分 | `worst-possible-idea` | 明标极端→提取→正常场景 |
| 材料多但关系不清 | `kj-affinity` | 自底向上归组，保留张力/离群，分组不即采用 |
| 需要让初稿发生接力变形 | `brainwriting-6-3-5` | 有界接力保留父稿，不预设人数/轮数/独立收益 |
| 愿景、实现、质疑互相打断 | `disney-strategy` | 分离三功能后给修订，不预设三专家或三报告 |
| 完整候选需要有依据比较 | `anchored-decision-matrix` | 锚点/依据/未知/敏感性与真实决定分开 |

只需明确小修改就直接做，不先套方法。只是没看懂先改表达；真的没兴趣再换机制，不能用同一种发散继续加十个标题。复杂证据缺口按需接Knowledge/Web/GAD，普通比较不用先找专家。

每次正式Method Run一个主方法；换方法如实记录引用，不要求用户确认切换，也不把后台整理都登记为方法成果。来源为method-generated的Idea须能追到ready Method ID和实际Run。
