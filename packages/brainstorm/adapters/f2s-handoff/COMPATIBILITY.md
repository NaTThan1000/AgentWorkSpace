## Semantics

- 体验目标与完整闭环可以跨系统、多轮、多问题；不压成唯一假设。
- 必要表现/反馈保留具体因果与感受，不只交 UI 骨架。
- 核心输入有真实来源；非阻断的后续工程责任保留缺口及下一动作。
- Agent 可审核字段映射；用户拥有概念、原型意图和重要取舍。
- 若外部合同发生语义变化，先核对真实消费者及受影响测试，再更新绑定；不能只改版本号宣称接线通过。

结构检查、Agent 接收演练、实际制作、真人体验认可分开记录。外部仓只读，Brainstorm 不复制外部 owner 的历史兼容规则。
