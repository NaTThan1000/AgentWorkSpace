# Opportunity Thesis · Convergence Profile

## D/N/S/C

- D（demand）：实际或可观察行为；市场很大不是需求证据。
- N（narrative/expectation）：用户预期怎样完成任务、理解体验；不是营销口号。
- S（supply/substitution）：现有解法、替代品为何有效、平台可能吸收什么；不能只数竞品。
- C（capability）：已有能力/资产、缺口及取得成本；愿望不是交付能力。

透镜按问题调整。先落到用户片段，再决定查什么，不必每格同等深度。已知/假设/未知分开，外部结论不能重写原创来源。

## Status

`draft` 可讨论但未接受或仍有缺口；`return-to-brainstorm` 需重构问题/方向。`accepted` 需要 user/joint Decision 接受下一行动、验证上限和停止条件。结构完整、资料丰富或 Agent 高分不自动接受。

## Stop and return

至少有一个改变行动的可观察信号；验证说明对象、观察方法、资源上限和结果→行动。若所有结果都不改变行动，停止追加该项研究，不自动执行未经授权行动。

只有热度口号、来源不可查、关键成本被猜测替代、推翻锁定决定或新增预算时保持未决，修正问题或查证，可按需 GAD 分析。

## Example

每周交接反复询问最终文件。候选显示来源及决定链接，观察交接后重复询问是否减少。若问题实为责任人不明，自动摘要无效，改测责任提示。这是合成假设，不是真实研究或市场验证。
