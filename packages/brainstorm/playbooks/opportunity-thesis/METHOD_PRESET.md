# Opportunity Thesis · Method Preset

本预设只说明何时引用 ready method ID，不复制原子方法正文。具体步骤与退出条件以 [`../../methods/METHOD_ROUTER.md`](../../methods/METHOD_ROUTER.md) 和对应方法合同为准。

| 当前缺口 | 可选 Method ID | 交接产物 |
|---|---|---|
| 输入混杂、方向和个人偏好未分开 | `brain-dump` | 编号 Raw、决策对象与未解释歧义 |
| “用户会要”“供给未锁死”等前提未声明 | `assumption-reversal` | 事实/约束/假设清单与反转候选 |
| 主张只依赖品类标签或竞品类比 | `first-principles` | 最小行为事实、因果主张与未知项 |
| 需要从可验证目标倒推投入切片 | `future-backcasting` | 未来状态、里程碑和今日最小动作 |
| 正向论据太顺，缺少失败路径或替代解释 | `reverse-brainstorming` | 错判窗口的路径与正向防护候选 |
| 多个真实方向需要基于锚点比较 | `anchored-decision-matrix` | 比较、未知项、依据与 Decision 分离的记录 |

## Run rules

1. 一次只运行一个主方法；切换时闭合上一 Run 的 Input、Output 与退出状态。
2. D/N/S/C 不是 method ID；每格先标证据状态，再决定是否需要认知变换。
3. 有关键事实缺口即可查证；保留原始想法及来源，区分实际结果、转述和未知，不把模型市场摘要冒充 Evidence。
4. 无法写出会改变行动的信号时，不再扩展研究；保留当前默认行动与原因。
5. 不引用 placeholder，也不因“机会窗口”话题临时创造自动评分或市场预测方法。

## Concrete handoff

结果回到一次具体用户行动：现在怎样做、哪里受阻、候选改变什么、何种结果改变下一行动。先用片段碰撞，再决定深化哪些 D/N/S/C；证据表不能替代发散。
