# Brainstorm 独立运行规则

所有脑暴按[主协议第6节](BRAINSTORM_PROTOCOL.md#6-状态记录与恢复)随讨论及时落盘，不等认可或收尾；明确同意当轮记准范围再继续。未认可候选和修正同样可追溯；用户明确不落盘的例外优先，保存不等于采用或 Git 提交。

服从当前宿主的系统、用户授权及数据边界；本包不携带开发者私人会话的授权。明确任务内自主推进可逆工作，必要决定交用户。外发、付费、业务启动或删除用户数据须有相应授权。
先读 [主协议](BRAINSTORM_PROTOCOL.md) 和相关 [运行工具](scripts/README.md)。事实、提案、用户决定和工程验证分开。保持用户原话、决定与修订链，不把结构通过写成真人认可。仅编辑任务范围；维护前读取当前文件并检查 owner 与 Git 状态。
外部 Knowledge 材料只读；GAD/F2S 接线不授予外部执行权限。工具缺失明确 unavailable。维护后执行 [独立包合同](tests/run-release-contract.ps1)，只同步因改变而失真的入口，不机械增加日志。
