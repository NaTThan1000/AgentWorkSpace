# 方法来源与采用政策

一个链接不能同时证明来源可靠、可执行及实际有效。方法至少有可追溯来源，原始书目只证明书目信息；论文须按实际读取范围解释，实践页面可支持操作身份，不自动获得因果效果结论。纠错不得把本次未读来源更新成“已重读”。

机器记录在[public-sources.json](public-sources.json)，人读登记在[public-sources.md](public-sources.md)。来源层级按内容实际身份判断，Wikipedia不能标原始文献；论文中的二手历史说法也不是历史一手证据。优先相关一手材料，而非按标签数量投票。

新增/改用来源记录：作者/owner、URL、实际访问日、层级、许可状态、复用范围、读取层级、支持主张及不可外推边界。许可未核验时仅链接、元数据及有限事实转述；不复制长篇教材、专有案例、表格/图示。历史verified许可证未重新核验前不据此扩大复用，所有新正文/例子均由本仓重新编写。

`placeholder → ready`要求来源链可信，独有操作、输入/输出、失效停止和Agent适配可执行，展开正反例经语义/来源审读，相关结构与行为合同通过。审核可由Agent在授权内完成，不强制用户逐方法批准；但不得由字段齐全自动晋升。实际创意收益另记，未证明不写成已验证。

新策略依据有限时限定场景尝试；确定性错误直接修；反例触发收窄/撤回。方法维护不扩张知识只读边界、项目决定或运行权限。详见[维护入口](../../methods/MAINTENANCE.md)。

公开包只保留书目与复用限制。读取层级、支持主张与私人笔记由宿主在当前任务记录，不随包携带。
