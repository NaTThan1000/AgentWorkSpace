# 必要验证

**要区分的解释**：当前未知如何影响下一选择；已有材料已经能回答的部分不重复试验。

**操作**：最少需要改变、计算或观察什么，控制哪些混杂。一个主变量通常便于归因；确需交互试验时明确设计与成本，不把“唯一变量”当永久限制。

**判据**：什么结果支持、削弱或推翻哪种解释；样本和观察窗口为何足够，不事后移动阈值。

**执行与恢复**：已有授权覆盖哪些动作，操作者、实际预算、停止条件、失败恢复和资料去向。可直接验算／复现的先做，不把计划当执行。

**证据边界**：计算、模拟、技术检查、真实用户体验分别能证明什么。重要产品取舍和新增权限才交用户；已有授权内验证无需再请同意。
