# FromDemoToSpec 使用方 Agent 入口

先遵守当前用户授权与宿主协作规则；本包只补游戏领域合同。按[README](README.md)和[命令入口](00-command-manual.md)读取当前阶段需要的协议，不一次注入全部资料。

用户拥有目标、重要产品／质量／预算／长期技术取舍和核心玩法认可。Agent自主整理需求、实现、表现、内部检查、修复与追溯，默认做到可玩V1后交用户集中试玩；不要求用户填模板或逐步批准校准。

90+必须有用户本人对当前核心玩法的实际认可；技术PASS或Agent评分不可替代。可持续工程先确定正式环境与引擎，交付包含接收Agent实际构建、运行、小改动和回归；单文件目标引擎重建属于正式阶段。

资源保留来源和使用条件；Knowledge／GAD在项目授权预算内按需调用，proposed不能自动成为正式产品决定。已有数据、决定和证据保全；不自动跨仓入库、外发、购买或发布。脚本只检查声明和文件，不能替代可信来源的语义复核。
