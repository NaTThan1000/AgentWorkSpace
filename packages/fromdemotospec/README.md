# FromDemoToSpec · Agent 游戏原型工作流 v2

提供从需求到可玩原型、体验迭代和Agent正式开发接续的协议、模板与工具。首次V1需要完整闭环、功能、理解、表现反馈、可靠性和追溯共同达标；90+必须有用户本人对核心玩法的真实认可。

直接告诉Agent：“按FromDemoToSpec制作原型，目标体验是……，已有约束是……。请自主完成规则、表现和内部检查，到可玩V1后集中交我试玩。”

从[命令入口](00-command-manual.md)进入[制作流程](protocols/prototype-workflow.md)、[质量](protocols/quality-and-evidence.md)、[表现](protocols/presentation.md)与[交付](protocols/handoff-and-production.md)。小体量后续重建用[single-file](paths/single-file.md)；保留工程继续开发用[maintained-project](paths/maintained-project.md)，实现前明确正式环境与引擎。

[项目入口](templates/project-entry.md)、[设计底稿](templates/design-baseline.md)、[决定与问题](templates/decisions-and-issues.md)、[验证与交付](templates/verification-and-delivery.md)由Agent维护，可合并而不要求用户填表。[设计模块](design-modules/README.md)按需使用；正式开发用[功能切片](templates/production-slice.md)。[单文件示例](examples/single-file-workflow.md)与[可持续示例](examples/maintained-workflow.md)是虚构填写参考，没有游戏或真人验收。

工具见[scripts](scripts/README.md)，项目状态字段与局限见[项目工具](docs/project-tools.md)。[资源支持](experience-kits/README.md)与[GAD](adapters/game-analysis-decision/README.md)在实际具备对应能力时按需用；工具转换不意味着外部分析已运行。不能自动入库、外发或扩大项目范围。

本包不包含引擎工程模板、真实Demo或整套资产库；具体工程起点在真实项目中建立并运行验证。框架合同PASS不能替代游戏品质、用户认可、真实接收或跨项目成本收益。
