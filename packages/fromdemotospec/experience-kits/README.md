# 体验与资源支持 · v2

以[表现协议](../protocols/presentation.md)为现行权威。在真实可玩片段中校准理解、感受与一致性，Agent自主选择方向，不默认要求A/B/C档位、固定四层组合或人工预览批准。

[构建内校准](calibration/README.md)只生成一份短记录，复杂时再展开状态／衔接。skeletons、skins、casts、feedback目录中的旧组合说明可作局部参考，不能覆盖新协议的自主边界或恢复旧人工流水线。

新资源选择使用[schema2示例](../examples/presentation-selection-v2.json)：描述方向、理由和来源；choice.mode=agent表示普通自主选择，user-constraint需真实来源。旧schema1仅供历史项目显式兼容，不用于新项目默认生成。

用[scripts](../scripts/README.md)的导入器消费已审计PrototypeAssets导出。single-file生成内联索引，maintained-project保留项目文件；都保存许可收据、证据与哈希，支持离线核验。库不可用时选有明确使用条件的项目自绘／程序或生成资产，不伪造共享库审核。项目资产不自动晋升资源仓。

选择与清单结构见[selection schema](schemas/presentation-selection.schema.json)、[asset manifest schema](schemas/asset-manifest.schema.json)。许可内容与来源是否足以支持使用仍需语义审核，结构和哈希通过不能替代。
