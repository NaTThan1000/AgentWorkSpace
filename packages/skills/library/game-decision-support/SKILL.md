# 游戏决策支持

先确认当前要改变的判断。项目行为、约束与已作决定从宿主实际资料核对；经验、定义、案例和来源证词从可用知识库或公开原始材料取得；系统关系、替代解释和投入取舍需要针对当前问题建模。

若有 Knowledge，按其当前 Query 协议发现并读取正文；若有 GAD，按其 analysis 协议直接分析。通过宿主 README、模块目录或已审阅的替代能力定位，不假定相邻私有仓存在。两包都没有时，仍使用项目事实、用户材料、可用公开来源、计算或有界复现，交付条件性判断；缺少来源只收窄依赖结论。实际工具、联网和实验按当前授权，不声称未执行结果。

候选、来源清单、hash 和 prepared 不等于读过材料；专家选择或 request 不等于完成分析。把实际使用的材料、对判断的支持/挑战/改变、适用条件和剩余未知写回宿主已有记录，不新增同义台账。证据足够、信息重复、预算到达或下一证据需要外部条件时停止。

Query 保持只读，不自动入库、改知识正文、执行实验或接受决定。重要产品取舍、真实 Play 与新增授权仍归用户。方法出现实质反例时交实际 owner 修正或收窄；项目偏好留在项目。
