# 按实际宿主合同收尾

先读根 COMMAND_MANUAL.md 和目标项目领域合同，确认 owner、dirty/index、实际范围和授权。按风险验证受影响行为，保存必要决定与恢复证据；只同步真正失真的入口。

提交消息用英文 Conventional Commits，提交前核对完整消息、提交后回读实际消息与结果树；存在宿主检查器时运行适用入口，否则说明人工核验范围，不伪造机器 PASS。子仓提交后每一级直接父仓必须提交匹配的 160000 gitlink，不能只暂存。外发和发布仍需对应授权。

暂停时在所属项目保存 owner、scope、停点、恢复入口和下一动作。交付分别说明实现、验证、状态、Git 闭合、发布和人工验收，不把未执行项说成完成。
