# 按实际任务触发能力

能力已经完整提供，不再扫描“该装哪个 meta 零件”。

| 真实信号 | 行动 |
|---|---|
| 继续任务但当前事实不清 | 读项目恢复入口、文件/Git 和实际证据 |
| 下一关键判断缺材料/机制/反例 | 选择知识查询、研究或适用方法，记录实际消费 |
| 明确收尾或已授权交付 | 按完成合同核验实际结果和必要父指针 |
| 重复失败、真实反例或重要交付 | 找 owner，有具体增量再学习并更新消费者 |
| 用户要求保存长期偏好 | 按授权限定保存，不从单次选择自动画像 |
| 版本更新或明确健康检查 | 只检查受影响范围，先报告/计划，再按授权修复 |

没有信号不每轮空扫，不新增定时任务，不建立第二份业务台账。
