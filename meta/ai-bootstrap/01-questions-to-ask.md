# 搭建所需信息

只询问阻断下一必要动作的信息，已回答不重问，可从实际环境确认的不转交用户。

- 目标工作区路径；目录非空时检查已有 owner、Git、配置与数据，禁止静默覆盖。
- 当前 Agent 工具能怎样读取根规则/Skill；验证实际行为，不按模型名字推断权限。
- 用户需要的业务包。首批 Brainstorm/FromDemoToSpec/Knowledge 可按需加入，不能借安装自动启动下游业务。
- 外部动作或不可恢复操作所需的真实授权。名称、语言等可逆默认不设强制访谈。

Knowledge 可以空库接入并查询；首次消化前取得真实用途、主题与排除边界，不为了安装凭空替用户决定知识范围。assisted 仅用户明确选择时使用。
