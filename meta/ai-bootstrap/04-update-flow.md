# 版本更新、兼容与恢复

取得目标发布版本及对应 upgrades 说明，核对安装记录与当前框架修改。发布仓每版声明上一版及兼容/升级路径；未知版本不猜测，跨多版按声明链升级。

运行 `python scripts/workspace.py upgrade --target <目录>` 预览。未修改的框架文件可以更新；本地修改且新版也变动时报告冲突；用户数据不替换。处理冲突后加 --apply，验证受影响行为与已接包入口。

事务失败自动尝试恢复已写框架文件；若出现并发修改则保留证据停止依赖动作。人工恢复先预览 rollback，再按事务 ID 应用，不覆盖事务之后的新改动。详细步骤见发布仓版本升级文档。

旧教学框架不批量删除私人文件。先备份识别旧职责、迁移规则与数据，再接入新根；历史记录保持原版本解释。更新不强制全工作区健康审查，也不重新询问功能组合。
