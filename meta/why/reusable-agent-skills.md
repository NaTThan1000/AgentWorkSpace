# 按任务触发可复用方法

状态：current-design（2026-10-09 完整版重构；实际收益按任务验证）

## 原理与做法

Skill 用名称/描述发现，用正文指导具体任务，用 references/scripts 提供按需细节。项目边界与正式决定仍由宿主拥有，Skill 不扩张授权或保证运行时一定加载。

## 条件与边界

单一源维护再生成必要平台镜像，避免手工多份分叉。验证触发、路径和真实消费者，不把格式 PASS 称为方法有效；强制业务门应放在实际入口或控制器，不能只依赖口头提醒。
