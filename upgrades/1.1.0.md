# 1.1.0 · 历史版本 / Historical release

本页定位历史发行。该版自动改名与别名支持仅存在于原不可变 tag，当前全称接口不再包含它们。原有事务恢复应使用生成事务的原版工具。当前版本见 [1.4.0 说明](1.4.0.md)。

This page identifies a historical release. Its automatic renaming and alias support remain in the original immutable tag and are absent from current full-name interfaces. Recover old transactions with their original release tool. See the [1.4.0 notes](1.4.0.md) for current behavior.
