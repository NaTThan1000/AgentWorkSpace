# 1.3.1 from 1.3.0

修复 Windows 新项目初始化和素材导出在最终目录重命名时的短暂 EPERM/EACCES/EBUSY：最多追加 6 次重试，总等待不超过 1.575 秒。每次重试前重新确认目标不存在；其他写入者、持续拒绝或非访问类错误仍明确失败，不覆盖用户文件。不自动解除锁或提升权限。

兼容 1.3.0 的组件 ID、安装位置、已选 Skills、能力 profile、用户数据和事务。用 scripts/workspace.py upgrade --target <workspace> 预览，解决具体冲突后加 --apply；只升级已安装组件，不新增包或自动更新 Skill 副本。方法库正文没有改动，内层 Skill 库仍为 1.3.0。1.2.0 用户先使用 v1.3.0 升级，再用本版升级，不跳过已声明的前版。

恢复：以本次返回的 transaction 运行 workspace.py rollback --target <workspace> --transaction <id>，先预览再 --apply。检查应用后改动，保留冲突与备份；回到 1.3.0 不会删除用户业务数据。原 v1.3.0 tag 保持不变，其首次远端复核的 Windows 失败记录保留在维护证据中。

Compatibility: preserves 1.3.0 IDs, paths, providers, selected skills, user data and transaction history. Preview then apply upgrade of installed components only. The change bounds Windows directory-publication retries and rechecks for competing writers; permanent errors still fail visibly. Roll back the returned transaction without overwriting later edits. From 1.2.0, upgrade through 1.3.0 first.
