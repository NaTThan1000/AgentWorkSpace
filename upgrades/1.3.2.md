# 1.3.2 from 1.3.1

兼容模式增加 package 与宿主同类模块/工作流的审阅入口。audit 与 init/add/upgrade 计划返回 package_review 和 package_review_criteria；候选发现增加根目录下模块和 Skill 的入口文件，保持有界、只读、不执行现有模块。生成的兼容接入文档也提醒后续接线前审阅。依赖 ready 与业务兼容结论分开，具体复用、并存、适配方式仍由实际接入审查决定，不新增统一人工审批，也不自动合并流程或迁移用户数据。

兼容 1.3.1 的组件 ID、安装位置、state/profile schema、用户数据和已选 Skills；各业务包来源与正文未变。使用本版发布仓运行 python scripts/workspace.py upgrade --target <workspace> 预览，解决冲突后加 --apply。兼容模式会更新受管的 agent-workspace-compatibility.md；若用户编辑过该入口则报告冲突，先保留并审阅差异。full 模式保留原布局。之前版本先按原升级链到 1.3.1。

恢复：对升级返回的 transaction 先运行 workspace.py rollback --target <workspace> --transaction <id> 预览，再加 --apply。回滚还原 1.3.1 的安装记录与接入入口，保留用户业务数据；事务后修改仍按冲突处理。不改写已有 tag。

Compatibility: adds package/workflow review prompts and bounded entrypoint discovery without changing package payloads, IDs, locations or state/provider schemas. Dependency readiness does not certify integration. Upgrade only from 1.3.1; preview before applying. The managed compatibility entry gains review guidance, with local edits protected by conflicts. Full-mode layout is unchanged. Roll back the returned transaction to restore prior metadata and entry content while preserving user data and checking later edits.
